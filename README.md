

**Ciné Match** est une application web dynamique qui permet de découvrir les films populaires du moment, d'effectuer des recherches en temps réel et de gérer une liste de favoris persistance.

---

## ✨ Fonctionnalités

- 🌟 **Films populaires :** Récupération automatique des dernières tendances via l'API The Movie Database (TMDB).
- 🔍 **Recherche dynamique :** Filtrage des films instantané selon le titre saisi dans la barre de recherche.
- ⭐ **Système de notes :** Affichage d'un badge couleur adapté à la note du film (vert pour les bonnes notes, orange pour les moyennes, rouge pour les faibles).
- ❤️ **Gestion des favoris :** Ajout et suppression de films dans une liste personnelle accessible via un panneau latéral (*drawer*).
- 💾 **Persistance des données :** Sauvegarde automatique des favoris dans le `localStorage` du navigateur (les données restent conservées après rafraîchissement).

---

## 🛠️ Technologies utilisées

- **HTML5** — Structure sémantique de l'application
- **CSS3** — Design moderne et panneau latéral interactif
- **JavaScript (ES6+)** — Programmation asynchrone (`fetch`, `async/await`), manipulation du DOM et gestion du `localStorage`
- **API TMDB** — Source de données des films et des visuels
